## Padrões observados

1. Falta ≠ descaso. Falta = conflito com trabalho + esquecimento.
2. WhatsApp é o canal universal. App instalado é barreira.
3. A recepcionista é a interface humana do sistema — e ela precisa de ferramenta.
4. Vaga cancelada evapora. É a maior oportunidade de ganho rápido.
5. Cadastro/identidade é o ponto de maior desistência.
